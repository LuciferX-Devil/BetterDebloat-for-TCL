# Security reporting policy

Report security concerns privately using [Report a vulnerability](https://github.com/LuciferX-Devil/BetterDebloat-for-TCL/security/advisories/new) on this repository's Security tab. Do not put keys, personal configuration, identifiers, logs or unpatched exploit details in public issues. Do not report adaptation-specific issues to Gathin23 as though they maintain this adaptation.

Include the APK SHA-256, model/firmware, a minimal reproduction on your own device, expected/actual behavior, impact and safe mitigation. Remove private data before submission. The maintainer should acknowledge, reproduce in isolation, coordinate a mitigation, test a fix and agree on disclosure. No response-time or ongoing support guarantee is made.

Only the TCL 55C845 / G08 build tested on Android 14 firmware V8-T653T01-LF1V669 is covered by the validation record. Other devices, firmware revisions and third-party modifications are untested. Known limitations, including network ADB, shared-file IPC, existing debug signing and recovery scope, are documented in README.md. Antivirus results are not security certification.
